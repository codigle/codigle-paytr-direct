# Codigle PayTR Direct

Sanitized source backup of the Codigle PayTR Direct WordPress/WooCommerce payment integration.

## Included

Only the `codigle-paytr-direct` plugin source.

## Not included

- Codigle Core
- Codigle Plan Builder
- Codigle Catalog
- Codigle Customer Portal
- Codigle Identity / Auth UI
- Codigle Theme
- WordPress configuration
- Database dumps
- Orders or customer data
- PayTR merchant credentials
- Raw payment tokens
- PAN / CVV
- Private keys or certificates

Production credentials must never be committed to Git.
